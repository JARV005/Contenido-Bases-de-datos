Escalar

Primera función: calcular IVA

CREATE OR REPLACE FUNCTION calcular_iva(p_precio DECIMAL)
RETURNS DECIMAL
LANGUAGE plpgsql
AS $$
DECLARE
    C_IVA CONSTANT DECIMAL := 0.19;
BEGIN
    RETURN ROUND(p_precio * (1 + C_IVA), 2);
END;
$$;

-- ⚡ Se usa DENTRO de un SELECT
SELECT nombre, precio,
       calcular_iva(precio) AS precio_con_iva
FROM productos;
Escalar

Función con lógica condicional

CREATE OR REPLACE FUNCTION clasificar_precio(p_precio DECIMAL)
RETURNS VARCHAR
LANGUAGE plpgsql AS $$
BEGIN
    RETURN CASE
        WHEN p_precio > 1000000 THEN 'PREMIUM'
        WHEN p_precio > 300000  THEN 'ESTÁNDAR'
        WHEN p_precio > 50000   THEN 'ECONÓMICO'
        ELSE 'BÁSICO'
    END;
END; $$;

-- Combinar varias funciones
SELECT nombre, precio,
       clasificar_precio(precio) AS categoria,
       calcular_iva(precio) AS precio_iva
FROM productos ORDER BY precio DESC;
SQL puro

Funciones en LANGUAGE sql

CREATE OR REPLACE FUNCTION precio_con_descuento(
    p_precio DECIMAL, p_descuento DECIMAL
)
RETURNS DECIMAL
LANGUAGE sql
AS $$
    SELECT ROUND(p_precio * (1 - p_descuento / 100), 2);
$$;

Ventajas de LANGUAGE sql

  • Más eficiente (el optimizador puede inline)
  • Más simple para cálculos puros
  • Sin BEGIN/END necesario

Cuándo usar plpgsql

  • Necesitas variables (DECLARE)
  • Necesitas IF / LOOP
  • Necesitas manejo de errores
De tabla

Funciones que devuelven tablas

CREATE OR REPLACE FUNCTION buscar_productos(p_termino VARCHAR)
RETURNS TABLE(
    producto_id     INT,
    producto_nombre VARCHAR,
    producto_precio DECIMAL,
    producto_stock  INT
)
LANGUAGE plpgsql AS $$
BEGIN
    RETURN QUERY
        SELECT id, nombre, precio, stock
        FROM productos
        WHERE nombre ILIKE '%' || p_termino || '%'
        ORDER BY nombre;
END; $$;

-- Se usa como una tabla
SELECT * FROM buscar_productos('lo');
De tabla

RETURNS TABLE vs RETURNS SETOF

RETURNS TABLE

  • Defines columnas custom
  • Nombres y tipos a medida
  • Más flexible
RETURNS TABLE(
  id INT,
  total DECIMAL
)

RETURNS SETOF

  • Devuelve filas de un tipo existente
  • Estructura exacta de una tabla
  • Más simple cuando aplica
RETURNS SETOF productos
Rendimiento

Volatilidad de funciones

IMMUTABLE

  • Mismos inputs = mismo output
  • PostgreSQL cachea el resultado
  • Ejemplo: calcular_iva()

STABLE

  • Mismo resultado en la misma transacción
  • Lee datos pero no los modifica
  • Se puede usar en índices

VOLATILE (default)

  • Puede dar resultados diferentes cada vez
  • Sin optimización del planificador
  • Modifica datos o depende de estado externo

Declarar correctamente la volatilidad mejora el rendimiento de queries complejos.
